# Custom-Drone-Chassis
A repo containing the design and 3D print process for a custom drone body

There are two folders (Generative and Modelled). The former is for CAD files that uses Autodesk Fusion's generative modelling function and contains designs for a lighter airframe.
The latter contains CAD files for a chassis that was designed and 3D printed to serve as a more robust body.
The function of this body was to allow me to improve my drone skills without worry of damaging components as well as eventually carrying out automated tasks (like carrying objects).
